    Backup
    Porquê, quando e como fazer backup

    Porque é importante

    Esta app não tem conta nem nuvem: os teus dados ficam só neste aparelho, dentro do navegador. É isso que a torna privada e gratuita, mas também quer dizer que ninguém os guarda por ti. Se limpares os dados do navegador, desinstalares a app, trocares de telemóvel, ele se avariar ou se perder, os dados perdem-se e não há como os recuperar. O backup é uma cópia num ficheiro, e é a tua única proteção.

    De quanto em quanto tempo

    • Se registas todos os dias, faz um backup uma vez por semana. Se registas menos, de 2 em 2 semanas chega.
    • Faz também um antes de apagar tudo, antes de importar outro backup e antes de trocar de telemóvel.
    • A app avisa-te aqui no Início quando passam X dias desde o último. Podes escolher o X mais abaixo (por defeito, 14).

    Backup protegido por palavra-passe

    «Exportar backup protegido» cifra o ficheiro com uma palavra-passe que escolhes. Sem ela ninguém o abre, nem tu: se a perderes, o backup não se recupera. Para importar, a app pede a palavra-passe. Recomendo-o se vais guardar o ficheiro em email ou nuvem.

    Onde guardar o ficheiro

    Fora do aparelho onde usas a app: por exemplo, enviar para o teu email ou guardar no teu serviço de nuvem (Google Drive, iCloud, OneDrive) ou no computador. Se o ficheiro ficar só no telemóvel, perdes tudo junto. O ficheiro tem os teus dados financeiros: guarda-o num sítio só teu.

    Passar os dados do telemóvel para o computador (ou ao contrário)

    1. No aparelho de onde vêm os dados: Início → Backup → Exportar backup (JSON).
    2. Leva o ficheiro para o outro aparelho: email para ti, WhatsApp para ti, nuvem ou cabo.
    3. No outro aparelho, abre a app: Início → Backup → Importar backup e escolhe o ficheiro.
    4. A app mostra um resumo do que vai importar. Confirma com «Substituir dados».

    Atenção: importar substitui tudo o que está no aparelho de destino. Não é uma sincronização: os dois aparelhos não se atualizam sozinhos. Se registares em ambos, o que escreveste num não aparece no outro. Escolhe um aparelho como principal, ou exporta e importa sempre que mudares de aparelho.

    Exportar para Excel (CSV)

    Ficheiros que abrem no Excel ou no Google Sheets. Não substituem o backup: para guardar tudo e voltar a importar, usa o backup (JSON).
